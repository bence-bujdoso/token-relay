🏗️ Architecture: How TokenRelay Works

🎯 Adaptive Compression Engine

The IntentClassifier categorizes user prompts into query, command, request, feedback, or system intents. The AdaptiveCompressor applies context-aware compression strategies optimized for each intent type.

ATC

🐝 Swarm Intelligence

TokenRelay delegates tasks to a swarm of specialized subagents — research, summarizer, optimizer, validator, compressor, refiner, critic, and synthesizer. Each subagent focuses on a specific aspect, communicating token-to-token for efficient outputs.

Swarm

🧠 Reinforcement Learning

A ReinforcementLearner tracks subagent performance over time, learning which agent configurations and delegation strategies yield the best token efficiency for different prompt types.

RL

⚡ Pipeline Orchestration

The V3Orchestrator coordinates the full pipeline: Adaptive Compression → Context-Aware Routing → Boundary Protocol → Optimization Strategy → Token Efficiency Quality → Enhanced Pipeline Control.

V3

✅ Benefits of TokenRelay

📉 Token Efficiency

Specialized subagents communicate in a shared token language, avoiding redundant context and producing focused outputs — typically 5-25% fewer tokens than a single-pass Traditional LLM call.

🔄 No Caching

Every benchmark run calls the LLM fresh. No EdgeCache hits, no stale results. Each run is an independent measurement of real token usage.

🤖 8 Specialized Subagents

research_agent, summarizer_agent, optimizer_agent, validator_agent, compressor_agent, refiner_agent, critic_agent, and synthesizer_agent each handle a specific dimension — no single model needs to do everything.

📊 Transparent Metrics

See exactly how many subagents were delegated, which roles were used, and how they communicated. Full subagent info displayed per benchmark run.

⚖️ Intent-Based Scaling

Subagent count adapts to task complexity: queries/commands/requests use 8 agents, feedback uses 6, system prompts use 5. Right-sized delegation for every task.

🔒 No Hardcoded Prompts

No hardcoded key phrases, compressed prompt lengths, or artificial restrictions. The original prompt flows through the full pipeline — the LLM decides the output naturally.

🐝 Subagent Pool

Each subagent has a specialized role in the delegation pipeline. The SwarmCoordinator creates and manages them based on the detected intent.
